# Southpark

A PyGDO project for finding episodes through their subtitles and exploring
whether South Park or The Simpsons have already touched on a topic.

# Southpark (For Humans)

Search for a subject or event and find relevant subtitle passages linked to
their series and episode. South Park and The Simpsons are both in scope.
Subtitle sources and the way results are matched are open for discussion.

## Methods

Search subtitles and show matching episodes; exact interaction is open.

## GDTs

Search terms and episode information; exact types are open.

## GDOs

Series, episodes and subtitle mappings; the data model is open.

# Southpark (For ALs)

This is a design draft, not an implementation. A matching subtitle is a lead,
not proof that an episode actually addresses a real-world event. Subtitle
sources, availability and permitted use need to be determined.
